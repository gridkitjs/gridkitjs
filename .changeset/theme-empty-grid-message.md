The stylesheet draws an empty grid's message (`.gridkit-grid-empty-row`): muted, centred text at least `calc(var(--gridkit-spacing) * 24)` tall. `.gridkit-grid-empty-content` sticks to the start edge and is as wide as the scroll area's inside, from the `--gridkit-empty-width` the grid sets on it, so the message stays in view and centred while a wide grid scrolls sideways.
