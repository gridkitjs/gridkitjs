---
title: "Choosing packages"
description: "What each GridKit package does, which ones a React app installs, and when to add core, dom or export-xlsx yourself."
---

GridKit is split into six published packages, so an app installs only what it uses. A React app needs two of them: `@gridkitjs/react` and a theme, `@gridkitjs/theme-tailwind` or `@gridkitjs/theme-css`.

## The packages

| Package                     | What it holds                                                                                                                     | Install it                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `@gridkitjs/react`          | The `DataGrid` component, its hooks and its types.                                                                                | In every React app.                                                                         |
| `@gridkitjs/theme-tailwind` | The stylesheet: palette tokens, dark mode and the grid's styles, for Tailwind CSS v4.                                             | In every app that uses Tailwind. See [theming](/docs/theme-tailwind).                       |
| `@gridkitjs/theme-css`      | The same stylesheet as plain CSS, generated from `theme-tailwind`.                                                                | In place of `theme-tailwind`, in an app without Tailwind. See [plain CSS](/docs/theme-css). |
| `@gridkitjs/core`           | The grid's logic in plain TypeScript: column definitions, sorting, filtering, row grouping, aggregates, pagination and the state. | Comes with `react`. Add it yourself to import from it, as below.                            |
| `@gridkitjs/dom`            | Browser behaviours with no framework: pointer gestures, keyboard focus, observers, the virtualizer, overlays and menus.           | Comes with `react`. Needed directly only to build a renderer of your own.                   |
| `@gridkitjs/export-xlsx`    | The Excel export writer.                                                                                                          | Only to offer "Export to Excel". See [Excel export](/docs/export-xlsx).                     |

The split follows what each layer needs to run. `core` needs no DOM, so it runs in Node, in tests and on a server. `dom` needs a browser but no framework. `react` only draws: every decision the grid makes comes from `core`, and every browser behaviour from `dom`, so a renderer for another framework reuses both.

## A React app

<PackageInstall pkg="@gridkitjs/react @gridkitjs/theme-tailwind" />

That is the whole install for every feature in the React docs except Excel export. Import the stylesheet once, as the [quick start](/docs/react) shows, and import components and types from `@gridkitjs/react`, which re-exports the types its props use, such as `ColumnDefinition`, `FilterState` and `SelectionState`.

## Importing from core

Some helpers live only in `@gridkitjs/core`: `defineColumnsFromRows`, `resolveGridView`, `sortRows` and `filterRows`. The types `DataGrid` names need no import from core: `@gridkitjs/react` exports them too. To import a helper, add `core` to your own dependencies:

<PackageInstall pkg="@gridkitjs/core" />

Install the same version `@gridkitjs/react` depends on (`npm ls @gridkitjs/core` shows it), so the app keeps one copy. With npm a transitive import often resolves anyway, but pnpm and Yarn Plug'n'Play refuse an import of a package you did not list.

## Excel export

<PackageInstall pkg="@gridkitjs/export-xlsx" />

Register its writer on the grid with `exportWriters`, and "Export to Excel" joins the grid's export commands. CSV and JSON export are built in and need no extra package. See [Excel export](/docs/export-xlsx) and [export](/docs/react/export).

## Without Tailwind

`@gridkitjs/theme-tailwind` is compiled by your app's Tailwind CSS v4 build. Without Tailwind, install `@gridkitjs/theme-css` in its place: the same stylesheet as plain CSS, with the same tokens and class names. See [plain CSS](/docs/theme-css).

<PackageInstall pkg="@gridkitjs/react @gridkitjs/theme-css" />

## Versions

Each package carries its own version and changelog, so `react` and `theme-tailwind` need not share a number. [Stability](/docs/react/stability) says what each release may change: which parts semantic versioning covers from 1.0, and that a minor release may break until then.
