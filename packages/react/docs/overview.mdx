title: "Overview"
description: "React components for GridKit, built on @gridkitjs/core."
---

@gridkitjs/react renders semantic class names — gridkit-data-grid, header-cell, grid-row — and carries no styles of its own. Pair it with @gridkitjs/theme-tailwind, or target the same class names with your own stylesheet.

## Install

```ts
npm install @gridkitjs/react @gridkitjs/theme-tailwind
```

See [DataGrid](/docs/react/data-grid) for the component itself, [column templates](/docs/react/column-templates) for custom header and cell rendering, [resizing](/docs/react/column-resizing), [reordering](/docs/react/column-reordering), row/column/cell [selection](/docs/react/row-selection), or [events](/docs/react/events) for every callback prop. See [theming](/docs/theme-tailwind) for palette tokens and dark mode.
