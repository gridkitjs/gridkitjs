title: "Overview"
description: "React components for GridKit, built on @gridkitjs/core."
---

@gridkitjs/react renders semantic class names — gridkit-data-grid, header-cell, grid-row — and carries no styles of its own. Pair it with @gridkitjs/theme-tailwind, or target the same class names with your own stylesheet.

It is the drawing layer only: what the grid does — its state, the rows and columns it shows, every action — comes from [@gridkitjs/core](/docs/core)'s controller, and its browser behaviours — gestures, keyboard focus, virtualization, announcements — from [@gridkitjs/dom](/docs/dom). Both are installed with it.

## Install

```ts
npm install @gridkitjs/react @gridkitjs/theme-tailwind
```

See [DataGrid](/docs/react/data-grid) for the component itself, [column templates](/docs/react/column-templates) for custom header and cell rendering, [resizing](/docs/react/column-resizing), [reordering](/docs/react/column-reordering), row/column/cell [selection](/docs/react/row-selection), or [events](/docs/react/events) for every callback prop. The [toolbar](/docs/react/toolbar), [context menu](/docs/react/context-menu) and [column chooser](/docs/react/column-chooser) each have a page; [localization](/docs/react/localization) covers translating the grid, [controlled state](/docs/react/state) holding its state yourself and saving it, [accessibility](/docs/react/accessibility) its keyboard model and announcements, and the [imperative handle](/docs/react/imperative-handle) its `ref`. See [theming](/docs/theme-tailwind) for palette tokens and dark mode.
