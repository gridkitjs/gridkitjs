---
title: "Imperative handle"
description: "The DataGridApi reached through DataGrid's ref — reading and setting live grid state, saving and restoring it, and triggering focus, scroll, and selection actions."
---

`DataGrid` accepts a `ref` typed `Ref<DataGridApi<Row>>`, for driving the grid from outside: the grid's DOM nodes, getters and a setter for every slice of its state, saving and restoring that state as a whole, and the handful of actions every grid ref carries.

```ts
import { useRef } from "react";
import { DataGrid, type DataGridApi } from "@gridkitjs/react";

const gridRef = useRef<DataGridApi<Row>>(null);

<DataGrid ref={gridRef} columns={columns} dataSource={rows} />;

gridRef.current?.scrollToRow("42");
gridRef.current?.getColumnSizing();
```

Every getter reads the grid's state at the moment it is called, so a read straight after an action sees the action's result. Every setter changes the grid as the user's own interaction would: it fires the slice's `on*Change` callback once, fires nothing when the new value equals the current one, and — for a slice you hold with a [controlled prop](/docs/react/state) such as `columnSort` — only asks, through that callback, as a click would.

## Elements

| Member    | Type                       | Description                                                                                                                                                                        |
| --------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `element` | `HTMLDivElement \| null`   | The grid's scrollable viewport element.                                                                                                                                            |
| `table`   | `HTMLTableElement \| null` | The row-area `<table>`, the one holding `<tbody>`. The header and, when aggregates are active, the footer are sibling `<table>`s outside it; `element` reaches the whole viewport. |

## Reading state

| Member                  | Returns                                     | Description                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getRows()`             | `readonly ResolvedRow<Row>[]`               | Rows as currently filtered and sorted — what's rendered, ungrouped.                                                                                                                                                                                                                                                                                                                                       |
| `getDisplayRows()`      | `readonly DisplayRow<Row>[]`                | `getRows()` regrouped into the active `groupBy` — group headers interleaved with data rows, in render order. Identical to `getRows()` when `groupBy` is empty. Each group header's `aggregates` field carries that group's own computed results; under `groupAggregateDisplay: "row"`, a group's own summary row (`kind: "group-summary"`) is interleaved right after it, carrying the same `aggregates`. |
| `getPageRows()`         | `readonly DisplayRow<Row>[]`                | The current page of `getDisplayRows()` — exactly the rows the body renders. All of `getDisplayRows()` when `paginated` is off. See [pagination](/docs/react/pagination).                                                                                                                                                                                                                                  |
| `getDataColumns()`      | `readonly DataColumn<Row>[]`                | Every column in its current order as `{ id, column }`, hidden ones included — what sorting, filtering and grouping read. See [column visibility](/docs/react/column-definition#column-visibility).                                                                                                                                                                                                        |
| `getColumns()`          | `readonly ResolvedColumn<Row>[]`            | Columns as currently sized and ordered — what's rendered, so hidden columns are left out.                                                                                                                                                                                                                                                                                                                 |
| `getColumnSizing()`     | `ColumnSizingState`                         | Column widths, keyed by column id.                                                                                                                                                                                                                                                                                                                                                                        |
| `getColumnOrder()`      | `ColumnOrderState`                          | Column ids in their current render order.                                                                                                                                                                                                                                                                                                                                                                 |
| `getColumnVisibility()` | `ColumnVisibilityState`                     | Columns shown (`true`) or hidden (`false`) since the grid mounted, keyed by id. A column absent from it follows its definition's `hidden`.                                                                                                                                                                                                                                                                |
| `getColumnSort()`       | `ColumnSortState`                           | The active sort, in priority order.                                                                                                                                                                                                                                                                                                                                                                       |
| `getFilter()`           | `FilterState<Row>`                          | The active filter. See [column filtering](/docs/react/column-filtering).                                                                                                                                                                                                                                                                                                                                  |
| `getGroupBy()`          | `GroupByState`                              | The active group-by stack, outer to inner. See [row grouping](/docs/react/row-grouping).                                                                                                                                                                                                                                                                                                                  |
| `getGroupExpansion()`   | `GroupExpansionState`                       | Group ids currently collapsed.                                                                                                                                                                                                                                                                                                                                                                            |
| `getPagination()`       | `PaginationState`                           | The active page and page size. See [pagination](/docs/react/pagination).                                                                                                                                                                                                                                                                                                                                  |
| `getPageCount()`        | `number`                                    | How many pages the current page size splits the rows into — `1` whenever `paginated` is off.                                                                                                                                                                                                                                                                                                              |
| `getAggregates()`       | `AggregateResults`                          | The grand-total aggregate results. See [aggregate functions](/docs/react/aggregate-functions).                                                                                                                                                                                                                                                                                                            |
| `getRowSelection()`     | `SelectionState`                            | Selected row ids.                                                                                                                                                                                                                                                                                                                                                                                         |
| `getSelectedRows()`     | `readonly ResolvedRow<Row>[]`               | The selected rows, in selection order, among every row the filter lets through. See [row selection](/docs/react/row-selection#selecting-from-code).                                                                                                                                                                                                                                                       |
| `getColumnSelection()`  | `SelectionState`                            | Selected column ids.                                                                                                                                                                                                                                                                                                                                                                                      |
| `getCellSelection()`    | `CellSelectionState`                        | The selected cell, if any.                                                                                                                                                                                                                                                                                                                                                                                |
| `getFocusedCell()`      | `{ rowIndex: number; columnIndex: number }` | The cell currently holding the grid's single tab stop.                                                                                                                                                                                                                                                                                                                                                    |
| `getState()`            | `GridState<Row>`                            | Every slice of state in one object — what `restoreState` takes back. See [saving and restoring a layout](/docs/react/state#saving-and-restoring-a-layout).                                                                                                                                                                                                                                                |

## Resolved row and column

`getRows()` and `getColumns()` return `ResolvedRow<Row>` and `ResolvedColumn<Row>` — the same shapes the selection events carry, resolved once here so no other doc page repeats them.

`ResolvedRow<Row>`:

| Field          | Type     | Description                                                                                        |
| -------------- | -------- | -------------------------------------------------------------------------------------------------- |
| `rowId`        | `string` | This row's id, as `getRowId` (or the position fallback) resolved it.                               |
| `row`          | `Row`    | The row itself.                                                                                    |
| `rowIndex`     | `number` | Position among the rows as rendered — filtered and sorted, and paginated once `paginated` is on.   |
| `datasetIndex` | `number` | This row's absolute position in the whole filtered/sorted/grouped dataset, unaffected by the page. |

`ResolvedColumn<Row>`:

| Field              | Type                            | Description                                                                                                        |
| ------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `column`           | `ColumnDefinition<Row>`         | The column definition this was resolved from.                                                                      |
| `id`               | `string`                        | The column's id.                                                                                                   |
| `width`            | `number`                        | This column's current width, in px.                                                                                |
| `sized`            | `boolean`                       | Whether `width` came from a user resize rather than the column definition or an auto-fit.                          |
| `label`            | `Node \| string`                | What the header shows: the column's own `headerTemplate`, else its `header`, else a label read off the field path. |
| `resizable`        | `boolean`                       | Whether this column can be resized, after the grid-level default.                                                  |
| `reorderable`      | `boolean`                       | Whether this column can be dragged, after the grid-level default.                                                  |
| `groupByDraggable` | `boolean`                       | Whether this column's header may be dragged into the group-by bar, after the grid-level default.                   |
| `alignment`        | `"left" \| "center" \| "right"` | How this column's cells align, after falling back to its type.                                                     |

## Actions

| Member                               | Description                                                                                                                                                       |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `focusCell(rowIndex, columnIndex)`   | Moves the grid's tab stop, and the browser's focus, to a cell.                                                                                                    |
| `clearSelection()`                   | Clears row, column, and cell selection together — the same as pressing <Kbd>Escape</Kbd>.                                                                         |
| `selectAllRows()`                    | Selects every data row on the current page, under `selectable.rows: "multiple"` only — the same as <Kbd>Ctrl</Kbd>+<Kbd>A</Kbd>.                                  |
| `selectRows(rowIds, intent?)`        | Selects rows by id within `selectable.rows`: `"replace"` (the default) or `"toggle"`. Fires the row callbacks once, or not at all when nothing changed.           |
| `expandAllGroups()`                  | Expands every group at once, as the `group.expandAll` command ("Expand all groups") does.                                                                         |
| `collapseAllGroups()`                | Collapses every group currently shown at once.                                                                                                                    |
| `goToPage(pageIndex)`                | Moves to the given page, clamped into range. Fires `onPaginationChange`, or nothing when that is the page already shown.                                          |
| `nextPage()`                         | Moves to the next page. A no-op on the last page — `onPaginationChange` doesn't fire.                                                                             |
| `previousPage()`                     | Moves to the previous page. A no-op on the first page — `onPaginationChange` doesn't fire.                                                                        |
| `setPageSize(pageSize)`              | Changes the page size, resetting to the first page.                                                                                                               |
| `showColumns(columnIds)`             | Shows the given columns, each in the place it held. Fires `onColumnVisibilityChange` once, or not at all when every one was already showing.                      |
| `hideColumns(columnIds)`             | Hides the given columns. A hidden column still sorts, filters and groups, and keeps its place in the order.                                                       |
| `scrollToRow(rowId, options?)`       | Scrolls the row with the given id into view, if it is currently shown.                                                                                            |
| `scrollToColumn(columnId, options?)` | Scrolls the column with the given id into view.                                                                                                                   |
| `autoFitColumn(columnId)`            | Sizes a shown column to fit its content, as double-clicking its resize handle does, firing `onColumnResize`. A hidden column, or one with no rows, is left alone. |
| `autoFitColumns(columnIds?)`         | `autoFitColumn` for each column given, or for every column shown when given none. Fitting more than one announces them once, as `columnsAutoFitted`.              |
| `openContextMenu(target, anchor?)`   | Opens the [context menu](/docs/react/context-menu#from-the-ref) `target` has, as a right-click there would. Returns whether it opened.                            |
| `closeContextMenu()`                 | Closes the context menu, if one is open.                                                                                                                          |
| `openColumnChooser()`                | Opens the [column chooser](/docs/react/column-chooser) at the grid's top-end corner, in place of any panel open. Closing it gives focus back to what had it.      |
| `runCommand(commandId, target?)`     | Runs a command by id on `target` — `{ area: "grid" }` by default — when it can run there, firing `onCommand`. Returns whether it ran.                             |
| `exportData(format, options?)`       | Exports the grid's view as a file of `format` without downloading it, and resolves to a `Blob` of it. See [export](/docs/react/export#from-the-ref).              |

`options` on `scrollToRow`/`scrollToColumn` is a standard
[`ScrollIntoViewOptions`](https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollIntoView),
passed straight through.

## Setting and restoring state

| Member                            | Fires                         | Description                                                                                                                                   |
| --------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `setColumnSort(sort)`             | `onColumnSortChange`          | Replaces the sort, naming the first column whose place or direction changed.                                                                  |
| `setFilter(filter)`               | `onFilterChange`              | Replaces the filter and goes back to the first page. See [column filtering](/docs/react/column-filtering#change-the-filter-from-your-own-ui). |
| `setGroupBy(groupBy)`             | `onGroupByChange`             | Replaces the group-by stack, naming the first level that changed.                                                                             |
| `setGroupExpansion(expansion)`    | `onGroupExpansionChange`      | Replaces the collapsed groups, reported with `groupId: null`.                                                                                 |
| `setPagination(pagination)`       | `onPaginationChange`          | Replaces the page and page size as given; a page past the last shows the last.                                                                |
| `setColumnSizing(sizing)`         | `onColumnResize`              | Replaces the widths, reported as the `"end"` of a resize of the first column that changed.                                                    |
| `setColumnOrder(order)`           | `onColumnOrderChange`         | Replaces the order, naming the first column whose position changed.                                                                           |
| `setColumnVisibility(visibility)` | `onColumnVisibilityChange`    | Replaces the visibility state, naming every column whose entry changed.                                                                       |
| `setRowSelection(selection)`      | row selection callbacks       | Replaces the selected row ids as given, whatever `selectable` allows.                                                                         |
| `setColumnSelection(selection)`   | column selection callbacks    | Replaces the selected column ids as given.                                                                                                    |
| `setCellSelection(selection)`     | cell selection callbacks      | Replaces the selected cell as given, `null` for none.                                                                                         |
| `restoreState(saved)`             | each changed slice's callback | Puts back state saved earlier, whole or in part; the grid re-renders once.                                                                    |

`getState()` holds the filter as given, so a `Date` value or a predicate entry won't survive `JSON.stringify`; pass it through `serializeGridState` (exported by both `@gridkitjs/react` and `@gridkitjs/core`) before saving it. See [saving and restoring a layout](/docs/react/state#saving-and-restoring-a-layout).

## Subscribing to state changes

```ts
subscribe(listener: () => void): () => void;
```

Registers `listener` to be called after any render in which the grid's internal state may have changed — any getter above may return a different value once it fires, not just one. Returns an unsubscribe function.

Most consumers should reach for one of the `use*State` hooks built on it instead of calling `subscribe` directly — each wraps it in [`useSyncExternalStore`](https://react.dev/reference/react/useSyncExternalStore) so a component elsewhere in the tree stays reactive with no `on*Change` prop to forward and no polling:

| Hook                       | Reads                                                                                                                                                      |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `usePaginationState`       | `getPagination`, `getPageCount` — see [pagination](/docs/react/pagination#building-a-pager-outside-the-grids-own-tree).                                    |
| `useGroupByState`          | `getGroupBy`, `getGroupExpansion` — see [row grouping](/docs/react/row-grouping#building-a-group-by-ui-outside-the-grids-own-tree).                        |
| `useColumnSortState`       | `getColumnSort` — see [column sorting](/docs/react/column-sorting#reading-sort-state-outside-the-grids-own-tree).                                          |
| `useSelectionState`        | `getRowSelection`, `getColumnSelection`, `getCellSelection` — see [row selection](/docs/react/row-selection#reading-selection-outside-the-grids-own-tree). |
| `useAggregateState`        | `getAggregates` — see [aggregate functions](/docs/react/aggregate-functions#reactively-outside-the-grids-own-tree).                                        |
| `useColumnSizingState`     | `getColumnSizing`.                                                                                                                                         |
| `useColumnOrderState`      | `getColumnOrder`.                                                                                                                                          |
| `useColumnVisibilityState` | `getColumnVisibility` — see [column visibility](/docs/react/column-definition#column-visibility).                                                          |
| `useFilterState`           | `getFilter`, plus `setFilter` — see [column filtering](/docs/react/column-filtering#change-the-filter-from-your-own-ui).                                   |

Each hook falls back to an empty/zero value before the grid mounts, the same way its matching getter would if called too early.
