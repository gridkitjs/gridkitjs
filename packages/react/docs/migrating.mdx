`DataGrid` covers most of what a Syncfusion `GridComponent` or an `AgGridReact` grid is used for: sorting, filtering, row grouping, aggregates, pagination, virtualization, selection, menus, a toolbar, export and print. Most features are a prop with a similar name. This page maps the common concepts, notes where the model differs, and lists what GridKit does not do yet, so you can check a screen before you move it.

## When to use it

Read it when moving a screen from either grid, or when comparing them. Check the [not yet](#not-yet) list first: a screen that depends on one of those features cannot move yet.

## How the model differs

- **State is props.** Each piece of state (sort, filter, row grouping, page, selection, column widths, order and visibility) is a prop pair: `defaultColumnSort` for the grid to keep it, or `columnSort` with `onColumnSortChange` for you to keep it. There is no `actionBegin`/`actionComplete` with a `requestType` to switch on, and nothing to set up through an API after the grid mounts. See [controlled and uncontrolled state](/docs/react/state).
- **Columns are data.** `columns` is an array of plain objects, as AG Grid's `columnDefs` is, rather than `ColumnsDirective` and `ColumnDirective` children.
- **The rows are an array.** `dataSource` takes rows, never a `DataManager`, an adaptor or a row model. The grid sorts, filters and pages the rows it holds; to do that on a server, hold the state and fetch. See [server-side data](/docs/react/server-side-data).
- **Styling is a stylesheet.** `@gridkitjs/theme-tailwind` styles the grid's semantic class names and needs Tailwind CSS v4. There are no theme modules to import per component. See [theming](/docs/theme-tailwind).
- **One edition.** Every package is MIT-licensed. Row grouping, an Excel-style filter, Excel export, the context menu and clipboard copy, which AG Grid keeps in its Enterprise edition, are part of it.
- **The handle is a ref.** `ref` gives a `DataGridApi`, the counterpart of AG Grid's `gridRef.current.api` and of the methods on a Syncfusion grid instance. See [imperative handle](/docs/react/imperative-handle).

## Grid props

| GridKit                                   | Syncfusion                                  | AG Grid                                       |
| ----------------------------------------- | ------------------------------------------- | --------------------------------------------- |
| `DataGrid`                                | `GridComponent`                             | `AgGridReact`                                 |
| `dataSource`                              | `dataSource`                                | `rowData`                                     |
| `columns`                                 | `ColumnsDirective`                          | `columnDefs`                                  |
| `getRowId`                                | `isPrimaryKey` on a column                  | `getRowId`                                    |
| `height`                                  | `height`                                    | The container's height, or `domLayout`        |
| `sortableColumns`                         | `allowSorting`                              | `sortable` on a column                        |
| `defaultColumnSort`                       | `sortSettings`                              | `sort` or `initialSort` on a column           |
| `columnSort` and `onColumnSortChange`     | `actionComplete` with `requestType` sorting | `onSortChanged`                               |
| `filterableColumns`                       | `allowFiltering` and `filterSettings`       | `filter` on a column                          |
| `{...excelFilter}`                        | `filterSettings` with `type: "Excel"`       | The Set Filter (Enterprise)                   |
| The toolbar's `"search"` box              | The toolbar's `"Search"` item               | `quickFilterText`                             |
| `groupableColumns`, `defaultGroupBy`      | `allowGrouping`, `groupSettings`            | `rowGroup`, `enableRowGroup` (Enterprise)     |
| The group-by bar, `groupByBarVisibility`  | `groupSettings.showDropArea`                | `rowGroupPanelShow` (Enterprise)              |
| `aggregates`                              | `AggregatesDirective`                       | `aggFunc` on a column (Enterprise)            |
| `paginated`, `defaultPagination`, `pager` | `allowPaging`, `pageSettings`               | `pagination`, `paginationPageSize`            |
| `infiniteScroll`                          | `enableInfiniteScrolling`                   | The infinite row model                        |
| `virtualized`                             | `enableVirtualization`                      | On by default                                 |
| `resizableColumns`                        | `allowResizing`                             | `resizable` on a column                       |
| `reorderableColumns`                      | `allowReordering`                           | On by default; `suppressMovable` turns it off |
| `selectable={{ rows: "multiple" }}`       | `selectionSettings`                         | `rowSelection`                                |
| `selectable={{ cells: "single" }}`        | `selectionSettings` with `mode: "Cell"`     | Cell selection (Enterprise)                   |
| `contextMenu`                             | `contextMenuItems`                          | `getContextMenuItems` (Enterprise)            |
| `toolbar`                                 | `toolbar`                                   | None built in                                 |
| `getRowProps`                             | The `rowDataBound` event                    | `getRowClass`, `rowClassRules`                |
| `onRowClick`, `onRowDoubleClick`          | `recordClick`, `recordDoubleClick`          | `onRowClicked`, `onRowDoubleClicked`          |
| `messages`, `locale`                      | `locale` with `L10n.load`                   | `localeText`                                  |

## Column definition fields

| GridKit                         | Syncfusion `ColumnDirective`    | AG Grid column definition       |
| ------------------------------- | ------------------------------- | ------------------------------- |
| `field`                         | `field`                         | `field`                         |
| `header`                        | `headerText`                    | `headerName`                    |
| `type`                          | `type`                          | `cellDataType`                  |
| `format`, `valueFormatter`      | `format`                        | `valueFormatter`                |
| `cellTemplate`                  | `template`                      | `cellRenderer`                  |
| `headerTemplate`                | `headerTemplate`                | `headerComponent`               |
| `alignment`                     | `textAlign`                     | `cellStyle` or `cellClass`      |
| `width`, `minWidth`, `maxWidth` | `width`, `minWidth`, `maxWidth` | `width`, `minWidth`, `maxWidth` |
| `hidden`                        | `visible: false`                | `hide`                          |
| `cellClassName`                 | `customAttributes`              | `cellClass`                     |

`field` reaches one level into a nested object as `"customer.name"`, as both grids do. `format` takes `Intl.NumberFormat` or `Intl.DateTimeFormat` options, `{ currency: "EUR" }`, rather than a format string such as Syncfusion's `"C2"`. See [column definitions](/docs/react/column-definition) for every field.

| ------------------------------------------ | --------------------------------------- | -------------------------------------- |

## A grid side by side

A Syncfusion grid like this one:

```tsx
<GridComponent
  dataSource={orders}
  allowSorting
  allowPaging
  pageSettings={{ pageSize: 20 }}
>
  <ColumnsDirective>
    <ColumnDirective field="id" headerText="Order" isPrimaryKey width={90} />
    <ColumnDirective field="customer" headerText="Customer" />
    <ColumnDirective field="total" headerText="Total" format="C2" />
  </ColumnsDirective>
  <Inject services={[Sort, Page]} />
</GridComponent>
```

or an AG Grid like this one:

```tsx
<AgGridReact
  rowData={orders}
  columnDefs={[
    { field: "id", headerName: "Order", width: 90 },
    { field: "customer", headerName: "Customer" },
    { field: "total", headerName: "Total", valueFormatter: formatMoney },
  ]}
  getRowId={(params) => String(params.data.id)}
  pagination
  paginationPageSize={20}
/>
```

becomes:

```tsx title="App.tsx"
import { DataGrid, type ColumnDefinition } from "@gridkitjs/react";

interface Order {
  id: number;
  customer: string;
  total: number;
}

const orders: Order[] = Array.from({ length: 60 }, (_, index) => ({
  id: index + 1,
  customer: `Customer ${String((index % 12) + 1)}`,
  total: Math.round(((index * 37) % 500) * 100 + 99) / 100,
}));

const columns: readonly ColumnDefinition<Order>[] = [
  { field: "id", header: "Order", type: "number", width: 90 },
  { field: "customer", header: "Customer" },
  {
    field: "total",
    header: "Total",
    type: "currency",
    format: { currency: "USD" },
  },
];

const getOrderId = (order: Order) => String(order.id);

export default function App() {
  return (
    <DataGrid
      columns={columns}
      dataSource={orders}
      getRowId={getOrderId}
      label="Orders"
      sortableColumns
      paginated
      defaultPagination={{ pageIndex: 0, pageSize: 20 }}
    />
  );
}
```

## Not yet

These are not in GridKit today. Each is absent from the source, not hidden behind an option:

- **Editing.** No inline cell or row editing, edit forms or edit events. A `cellTemplate` can render inputs of your own that write back to your rows.
- **Master-detail.** No detail row or panel that expands under a row.
- **Frozen columns.** No pinned or frozen columns; the header and footer stay put, but every column scrolls sideways. (The xlsx writer freezes the header row in the exported sheet, which is not the same thing.)
- **Column groups and spanning.** No grouped headers over several columns, and no row or column spanning of cells.
- **Row drag.** No dragging rows to reorder them or to move them between grids. Columns and group-by chips can be dragged; rows cannot.
- **A server-side data adapter.** No `DataManager`, adaptor or server-side row model. Server-side sorting, filtering and paging work through controlled state instead; see [server-side data](/docs/react/server-side-data).
- **Tree data.** No hierarchical rows from a parent id or a path; [row grouping](/docs/react/row-grouping) groups flat rows by a column's values.
- **Cell ranges.** Cell selection is one cell at a time.
- **PDF export.** The "Export to PDF" command appears only once you register a `pdf` writer of your own; none ships. [Printing](/docs/react/printing) to the browser's "Save as PDF" is the built-in route.
