title: "Column resizing"
description: "Dragging a column wider with resizableColumns, resizeMode, and columnSizeDefaults."
---

`resizableColumns` turns on dragging a header's trailing edge to resize, unless a column sets its own `resizable` to override the grid. Double-clicking the edge fits the column to its content instead. `resizeMode` decides what happens to the rest of the grid: "fit" (the default) redistributes the space a resize gives up or takes among the other columns; "fixed" leaves every other column exactly where it was.

## Props

| Prop                                 | Type                                 | Default | Description                                                                                                                                                                  |
| ------------------------------------ | ------------------------------------ | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `resizableColumns`                   | `boolean`                            | `false` | Whether columns can be dragged wider, unless a column says otherwise.                                                                                                        |
| `resizeMode`                         | `"fit" \| "fixed"`                   | `"fit"` | Whether columns fill the grid's width or sit at their own.                                                                                                                   |
| `columnSizeDefaults`                 | `Partial<ColumnSizeDefaults>`        |         | Width, minWidth, maxWidth applied to a column that sets none of its own.                                                                                                     |
| `defaultColumnSizing`                | `ColumnSizingState`                  |         | Column widths to start from, keyed by column id. Uncontrolled.                                                                                                               |
| `columnSizing`                       | `ColumnSizingState`                  |         | Column widths, controlled — a drag or nudge asks through `onColumnResize` (every `"move"` too), whose `sizing` is the next state. See [controlled state](/docs/react/state). |
| `onColumnResize`                     | `(event: ColumnResizeEvent) => void` |         | Called as the user resizes a column: continuously with phase "move", once with "end".                                                                                        |
| `column.resizable`                   | `boolean`                            |         | Per-column override of resizableColumns — a column can opt out of an otherwise resizable grid, or in on one that is not.                                                     |
| `column.width / minWidth / maxWidth` | `number`                             |         | This column's own starting width and resize bounds.                                                                                                                          |

## Keyboard & pointer interactions

- Drag a header's trailing edge to resize; double-click it to size the column to its content.
- With a resizable header focused, <Kbd>Alt</Kbd>+<Kbd>ArrowLeft</Kbd> / <Kbd>Alt</Kbd>+<Kbd>ArrowRight</Kbd> nudge the width and <Kbd>Alt</Kbd>+<Kbd>Enter</Kbd> sizes the column to its content, as double-clicking the edge does; <Kbd>Escape</Kbd> cancels an in-progress resize.

## Autofit

Sizing a column to its content — a double-click on its edge, <Kbd>Alt</Kbd>+<Kbd>Enter</Kbd> on its header — measures the column's content in the rows on screen and fits the column to it, within its `minWidth`/`maxWidth`, firing `onColumnResize` once with `"end"`. On a paginated or virtualized grid, rows not drawn are not measured. The same fit is available from code: the ref's [`autoFitColumn(columnId)`](/docs/react/imperative-handle#actions) and `autoFitColumns(columnIds?)`, which fits every column shown when given none, and the `column.autoFit` and `column.autoFitAll` commands, which a [context menu](/docs/react/context-menu#default-items) or [toolbar](/docs/react/toolbar) can carry or `runCommand` can run.

## Reading column widths outside the grid's own tree

`useColumnSizingState` subscribes to the grid's column widths through its `ref`, for a component living elsewhere on the page:

```tsx title="App.tsx"
import { useRef, type RefObject } from "react";
import {
  DataGrid,
  useColumnSizingState,
  type ColumnDefinition,
  type DataGridApi,
} from "@gridkitjs/react";

interface Book {
  id: number;
  title: string;
  author: string;
}

const books: Book[] = [
  { id: 1, title: "Kindred", author: "Butler" },
  { id: 2, title: "The Dispossessed", author: "Le Guin" },
];

const columns: readonly ColumnDefinition<Book>[] = [
  { field: "title", header: "Title" },
  { field: "author", header: "Author" },
];

function WidthReadout({
  gridRef,
}: {
  gridRef: RefObject<DataGridApi<Book> | null>;
}) {
  const sizing = useColumnSizingState(gridRef);
  return <p>{Object.keys(sizing).length} columns resized</p>;
}

export default function App() {
  const gridRef = useRef<DataGridApi<Book>>(null);
  return (
    <>
      <WidthReadout gridRef={gridRef} />
      <DataGrid
        ref={gridRef}
        columns={columns}
        dataSource={books}
        getRowId={(row) => String(row.id)}
        label="Books"
        resizableColumns
      />
    </>
  );
}
```

`useColumnSizingState` only reads. To change column widths from code, call the ref's `setColumnSizing(sizing)`, which fires `onColumnResize`, or hold it yourself with the controlled `columnSizing` prop. Before the grid mounts, the hook reads as an empty object. See [imperative handle](/docs/react/imperative-handle) for `getColumnSizing` and `subscribe`.
