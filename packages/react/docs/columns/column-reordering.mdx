---
title: "Column reordering"
description: "Dragging a column into a new position with reorderableColumns."
---

`reorderableColumns` turns on dragging a header to a new position, unless a column sets its own `reorderable` to override the grid. A column that can't move can still be moved past — dragging one past a fixed column is fine, only the fixed one can't itself be picked up.

## Props

| Prop                  | Type                                | Default | Description                                                                                                                                       |
| --------------------- | ----------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `reorderableColumns`  | `boolean`                           | `false` | Whether columns can be dragged into a new position.                                                                                               |
| `defaultColumnOrder`  | `readonly string[]`                 |         | Column ids in the order to start in. Uncontrolled, and partial — ids it omits keep their position among columns.                                  |
| `columnOrder`         | `readonly string[]`                 |         | The column order, controlled — a drop asks through `onColumnOrderChange` instead of moving the column. See [controlled state](/docs/react/state). |
| `onColumnOrderChange` | `(event: ColumnOrderEvent) => void` |         | Called once when the user drops a column somewhere new. A drop that leaves the order unchanged does not call it.                                  |
| `column.reorderable`  | `boolean`                           |         | Per-column override of reorderableColumns. A column that cannot move can still be moved past.                                                     |

## Keyboard & pointer interactions

- Drag a header to reorder columns.
- With a header focused, <Kbd>Ctrl</Kbd>+<Kbd>ArrowLeft</Kbd> / <Kbd>Ctrl</Kbd>+<Kbd>ArrowRight</Kbd> reorders it via keyboard; <Kbd>Escape</Kbd> cancels an in-progress drag.

## Reading column order outside the grid's own tree

`useColumnOrderState` subscribes to the grid's column order through its `ref`, for a component living elsewhere on the page:

```tsx title="App.tsx"
import { useRef, type RefObject } from "react";
import {
  DataGrid,
  useColumnOrderState,
  type ColumnDefinition,
  type DataGridApi,
} from "@gridkitjs/react";

interface Book {
  id: number;
  title: string;
  author: string;
}

const books: Book[] = [
  { id: 1, title: "Kindred", author: "Butler" },
  { id: 2, title: "The Dispossessed", author: "Le Guin" },
];

const columns: readonly ColumnDefinition<Book>[] = [
  { field: "title", header: "Title" },
  { field: "author", header: "Author" },
];

function OrderReadout({
  gridRef,
}: {
  gridRef: RefObject<DataGridApi<Book> | null>;
}) {
  const order = useColumnOrderState(gridRef);
  return <p>Order: {order.join(", ") || "as declared"}</p>;
}

export default function App() {
  const gridRef = useRef<DataGridApi<Book>>(null);
  return (
    <>
      <OrderReadout gridRef={gridRef} />
      <DataGrid
        ref={gridRef}
        columns={columns}
        dataSource={books}
        getRowId={(row) => String(row.id)}
        label="Books"
        reorderableColumns
      />
    </>
  );
}
```

`useColumnOrderState` only reads. To change column order from code, call the ref's `setColumnOrder(order)`, which fires `onColumnOrderChange`, or hold it yourself with the controlled `columnOrder` prop. Before the grid mounts, the hook reads as an empty array. See [imperative handle](/docs/react/imperative-handle) for `getColumnOrder` and `subscribe`.
