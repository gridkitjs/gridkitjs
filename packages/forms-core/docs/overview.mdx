---
title: "Overview"
description: "Framework-free form-input logic for GridKit: values and drafts, events, parsing, validation and messages, with no DOM."
---

@gridkitjs/forms-core holds the logic behind GridKit's form inputs: the value a field holds and the draft being typed, the events an input fires and their order, parsing and formatting (numbers in every locale's way, exactly, among them), validation and the messages it produces. It has no DOM and no framework, so a field can be driven from a browser, a Node test or any renderer. @gridkitjs/forms-dom attaches it to real controls, and @gridkitjs/forms draws the React components on top.

You only need this package to write a forms renderer of your own. @gridkitjs/forms depends on it, so installing that is enough to use the inputs: the [forms overview](/docs/forms/overview) shows how to install it, import the stylesheet and write a first form.

<Callout type="note" title="First iteration, not yet published">
  The forms packages are a first iteration, under development and not on npm
  yet. Their API may change before the first release.
</Callout>

## Example

```ts
import {
  createFieldController,
  defaultFormsMessages,
  formatText,
  textParser,
} from "@gridkitjs/forms-core";

const field = createFieldController<string>({
  defaultParse: textParser(),
  defaultFormat: formatText,
  messages: defaultFormsMessages,
  onCommit: ({ value }) => {
    console.log(`committed ${String(value)}`);
  },
});

field.focus(null);
field.input({ text: "Ada", source: "typing", nativeEvent: null, input: null });
field.commit("enter", null); // logs "committed Ada"
```

## Stability

What an app writes against (the event and message types, the parse and format contract, the validators and `FormsMessages`) follows semantic versioning. What only a renderer calls (`createFieldController`, `fieldReducer`, the field registry) is in the renderer tier: a minor release may change it, with the change called out in the changelog. The [forms stability section](/docs/forms/overview#stability) lists what is covered and the unions a minor release may grow.
