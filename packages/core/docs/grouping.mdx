title: "Row grouping"
description: "The row grouping transforms underneath groupBy, groupExpansion and the group-by bar."
---

`groupRows` reshapes filtered, sorted rows into nested groups, and the other functions here change the two pieces of state it reads: the group-by stack and which groups are expanded. The [view pipeline](/docs/core/view) and the [controller](/docs/core/controller) call them for you; reach for them directly in a custom adapter or group-by bar.

A `GroupByState` is `readonly GroupByEntry[]`, outer level first, each entry `{ columnId, direction? }` — a level's own `direction` orders its group values, not the rows inside a group. A `GroupExpansionState` is a mode with exceptions: `{ mode: "allExpanded", except }` expands every group but the ids in `except`, and `{ mode: "allCollapsed", except }` collapses every group but those. The mode also covers groups not on screen yet (one under a collapsed parent, or one that appears after the state was set), so `except` holds only the groups toggled against it. An uncontrolled grid starts at `{ mode: "allExpanded", except: [] }`.

## Grouping rows

| Function                                       | Type                         | Description                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `groupRows(rows, groupBy, expansion, columns)` | `readonly DisplayRow<Row>[]` | `rows` regrouped into `groupBy`'s levels: a header per distinct value at each level, ordered with `compareValues`, then its nested groups or data rows, depth first. A collapsed group contributes its header only. Returns `rows` itself when `groupBy` is empty or names only absent columns. |
| `groupRowId(path)`                             | `string`                     | A group's id, from the values of its levels outer to inner. Build ids with this, never by hand.                                                                                                                                                                                                 |

Filter and sort run first — [`resolveShownRows`](/docs/core/view#functions) does both — and grouping keeps their order within each group. `rowIndex` is renumbered across the output, headers included.

A `DisplayRow<Row>` is a data row (`ResolvedRow<Row>`, `kind: "data"`), a group header (`ResolvedGroupRow`, `kind: "group"`), or a group's summary row (`ResolvedGroupSummaryRow`, `kind: "group-summary"`, only from [`withGroupAggregates`](/docs/core/aggregation)). Tell them apart with `entry.kind`. A `ResolvedGroupRow` carries:

| Field          | Type                 | Description                                                                     |
| -------------- | -------------------- | ------------------------------------------------------------------------------- |
| `groupId`      | `string`             | Its id, `groupRowId(path)`: what `GroupExpansionState`'s `except` lists.        |
| `level`        | `number`             | Nesting depth, `0` for a top-level group.                                       |
| `columnId`     | `string`             | The column this level groups by.                                                |
| `value`        | `unknown`            | This level's value — the last entry of `path`.                                  |
| `path`         | `readonly unknown[]` | The value at every level from the top down to this one.                         |
| `expanded`     | `boolean`            | Whether the group is open.                                                      |
| `count`        | `number`             | Its leaf rows, collapsed or not.                                                |
| `rowIndex`     | `number`             | Its position among the rows as rendered.                                        |
| `datasetIndex` | `number`             | Its position in the whole grouped result, on any page.                          |
| `aggregates`   | `AggregateResults`   | Its own aggregate results, once `withGroupAggregates` has run; empty otherwise. |

## The group-by stack

`movesGroupBy` comes from `@gridkitjs/core/renderer`, for a drop indicator; `moveGroupByBefore` from `@gridkitjs/core`.

| Function                                               | Type           | Description                                                                                                                                                                                                                                                          |
| ------------------------------------------------------ | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `moveGroupByBefore(groupBy, columnId, beforeColumnId)` | `GroupByState` | `columnId` placed in front of `beforeColumnId`, or at the end for `null` — inserted when it is not grouped yet, moved when it is, so a header dropped on the bar and a chip dragged within it both use it. Returns `groupBy` itself for a move that changes nothing. |
| `movesGroupBy(groupBy, columnId, beforeColumnId)`      | `boolean`      | Whether that move would change anything, for a drop indicator that promises only real moves.                                                                                                                                                                         |

A moved level keeps its entry, and so its `direction`. To add or remove one level, the controller's `toggleGroupBy(columnId)` appends a column or takes it out.

## Expanding and collapsing

| Function                                   | Type                  | Description                                                                                                                                                                                                                                        |
| ------------------------------------------ | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isGroupExpanded(expansion, groupId)`      | `boolean`             | Whether `expansion` shows `groupId` open. Read the state through this rather than checking `except` by hand, since what membership means depends on the mode.                                                                                      |
| `toggleGroupExpansion(expansion, groupId)` | `GroupExpansionState` | `groupId` collapsed if it was open, opened if it was collapsed: it joins `except`, or leaves it, and the mode stays.                                                                                                                               |
| `expandAllGroups(expansion)`               | `GroupExpansionState` | `ALL_EXPANDED`: every group open, including those that appear later. Returns `expansion` itself when it already is `{ mode: "allExpanded", except: [] }`.                                                                                          |
| `collapseAllGroups(expansion)`             | `GroupExpansionState` | `ALL_COLLAPSED`: every group closed, including one under a collapsed parent (so reopening the parent shows its children closed) and those that appear later. Returns `expansion` itself when it already is `{ mode: "allCollapsed", except: [] }`. |

| Constant        | Value                                  | Description                                                               |
| --------------- | -------------------------------------- | ------------------------------------------------------------------------- |
| `ALL_EXPANDED`  | `{ mode: "allExpanded", except: [] }`  | Every group open, where an uncontrolled grid starts.                      |
| `ALL_COLLAPSED` | `{ mode: "allCollapsed", except: [] }` | Every group closed. Pass it as `defaultGroupExpansion` to start that way. |

## The group-by bar

`groupByBarVisibility` takes a `GroupByBarVisibility` — `"auto"` (the default) shows the bar while anything is grouped or a header that can be dropped on it is being dragged, `"always"` shows it regardless, and `"never"` hides it.

## In the React grid

`groupableColumns`, `groupByDraggableColumns` and `defaultGroupBy` turn grouping on — see [row grouping](/docs/react/row-grouping).
