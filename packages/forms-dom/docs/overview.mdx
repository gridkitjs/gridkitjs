---
title: "Overview"
description: "Framework-free browser behaviours for GridKit form inputs: the text-input pipeline, toggles, Enter navigation and focus helpers."
---

@gridkitjs/forms-dom holds every browser behaviour a form input needs that is not drawing: reading what the user types and pastes into a control, toggles, auto-grow, Enter navigation and moving focus. @gridkitjs/forms-core decides what a field does and runs without a DOM; @gridkitjs/forms-dom connects it to real controls, with no framework; a renderer such as @gridkitjs/forms draws the markup and attaches these behaviours to it.

You only need this package to write a forms renderer of your own. @gridkitjs/forms depends on it, so installing that is enough to use the inputs.

<Callout type="note" title="Not yet published">
  The forms packages are under development and are not on npm yet.
</Callout>

## Example

```ts
import { scheduleTimeout } from "@gridkitjs/forms-dom";

const cancel = scheduleTimeout(() => {
  console.log("300ms later");
}, 300);
// later, if it should not run after all:
cancel();
```

## Exports

Every export of `@gridkitjs/forms-dom`:

| Export                                                                                      | Kind            | Description                                                                                                                           | Page                                               |
| ------------------------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `attachTextInput`, `AttachedTextInput`, `TextControl`, `TextInputOptions`                   | function, types | Connects a native `<input>` or `<textarea>` to a forms-core field controller.                                                         | [Text pipeline](/docs/forms-dom/text-pipeline)     |
| `attachAutoGrow`, `AttachedAutoGrow`, `AutoGrowOptions`                                     | function, types | Grows a `<textarea>` with its text between a minimum and a maximum number of lines.                                                   | [Auto-grow](/docs/forms-dom/auto-grow)             |
| `attachToggle`, `AttachedToggle`, `ToggleOptions`                                           | function, types | Connects a native checkbox or switch to a forms-core field controller holding a boolean.                                              | [Toggles](/docs/forms-dom/toggles)                 |
| `attachEnterNavigation`, `findFirstInvalidControl`, `focusTargetIn`, `compareDocumentOrder` | functions       | Enter moving from field to field, the first invalid control of a form, the control a link should focus, document order.               | [Form navigation](/docs/forms-dom/form-navigation) |
| `scheduleTimeout`                                                                           | function        | The browser's timers as a forms-core [`Schedule`](/docs/forms-core/overview#exports): runs a callback once after a delay, cancelable. | This page                                          |
