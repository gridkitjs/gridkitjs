---
title: "Overview"
description: "Framework-free browser behaviours for GridKit form inputs: the text-input pipeline, stepping, toggles, Enter navigation and focus helpers."
---

@gridkitjs/forms-dom holds every browser behaviour a form input needs that is not drawing: reading what the user types and pastes into a control, toggles, auto-grow, Enter navigation and moving focus. @gridkitjs/forms-core decides what a field does and runs without a DOM; @gridkitjs/forms-dom connects it to real controls, with no framework; a renderer such as @gridkitjs/forms draws the markup and attaches these behaviours to it.

You only need this package to write a forms renderer of your own. @gridkitjs/forms depends on it, so installing that is enough to use the inputs: the [forms overview](/docs/forms/overview) shows how to install it, import the stylesheet and write a first form.

<Callout type="note" title="First iteration, not yet published">
  The forms packages are a first iteration, under development and not on npm
  yet. Their API may change before the first release.
</Callout>

## Example

```ts
import { scheduleTimeout } from "@gridkitjs/forms-dom";

const cancel = scheduleTimeout(() => {
  console.log("300ms later");
}, 300);
// later, if it should not run after all:
cancel();
```

## Exports

Every export of `@gridkitjs/forms-dom`:

| Export                                                                                                                                    | Kind             | Description                                                                                                                           | Page                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `attachTextInput`, `AttachedTextInput`, `TextControl`, `TextInputOptions`, `TextInputController`                                          | function, types  | Connects a native `<input>` or `<textarea>` to a forms-core field controller.                                                         | [Text pipeline](/docs/forms-dom/text-pipeline)                  |
| `attachAutoGrow`, `AttachedAutoGrow`, `AutoGrowOptions`                                                                                   | function, types  | Grows a `<textarea>` with its text between a minimum and a maximum number of lines.                                                   | [Auto-grow](/docs/forms-dom/auto-grow)                          |
| `attachStepKeys`, `AttachedStepKeys`, `StepKeysOptions`, `attachHoldRepeat`, `AttachedHoldRepeat`, `HoldRepeatOptions`, `HoldRepeatState` | functions, types | A number control stepped by keys and the wheel; a stepper button that repeats while held.                                             | [Stepping](/docs/forms-dom/stepping)                            |
| `attachToggle`, `AttachedToggle`, `ToggleOptions`                                                                                         | function, types  | Connects a native checkbox or switch to a forms-core field controller holding a boolean.                                              | [Toggles](/docs/forms-dom/toggles)                              |
| `attachEnterNavigation`, `findFirstInvalidControl`, `focusTargetIn`, `compareDocumentOrder`                                               | functions        | Enter moving from field to field, the first invalid control of a form, the control a link should focus, document order.               | [Form navigation](/docs/forms-dom/form-navigation)              |
| `attachFocusGroup`, `AttachedFocusGroup`, `FocusGroupOptions`                                                                             | function, types  | Tells focus moving between the parts of one input from focus leaving it, by Tab or otherwise.                                         | [Form navigation](/docs/forms-dom/form-navigation#focus-groups) |
| `scheduleTimeout`                                                                                                                         | function         | The browser's timers as a forms-core [`Schedule`](/docs/forms-core/overview#exports): runs a callback once after a delay, cancelable. | This page                                                       |

## Stability

This package is in the forms renderer tier: a minor release may change it, with the change called out in the changelog. The [forms stability section](/docs/forms/overview#stability) lists what is covered and the unions a minor release may grow.
