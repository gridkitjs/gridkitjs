---
title: "Overview"
description: "React form inputs and form structure for GridKit, styled by the GridKit themes to match the grid."
---

@gridkitjs/forms draws GridKit's form inputs and the structure around them in React, styled by the GridKit themes so a form beside a grid looks like part of it. @gridkitjs/forms-core decides what a field does, @gridkitjs/forms-dom connects it to the browser, and this package draws the markup and attaches them, with no styles of its own: the themes' forms stylesheet styles it. It works without the grid packages, and beside them.

<Callout type="note" title="Not yet published">
  The forms packages are under development and are not on npm yet.
</Callout>

## Example

Every input fires the same [events](/docs/forms/events). Until the inputs arrive, the hook they are built on binds a native control:

```tsx title="App.tsx"
import {
  formatText,
  textParser,
  useFieldInput,
  type FieldInputKind,
} from "@gridkitjs/forms";

const text: FieldInputKind<string> = {
  defaultParse: textParser(),
  defaultFormat: formatText,
  serialize: (value) => value,
};

export function App() {
  const field = useFieldInput(
    {
      name: "name",
      onCommit: (event) => {
        console.log(`committed ${String(event.value)}`);
      },
    },
    text,
  );
  return (
    <label>
      Name <input {...field.controlProps} />
      {field.hiddenInput}
    </label>
  );
}
```

## Exports

Every export of `@gridkitjs/forms`. Those marked as re-exported come from forms-core, so an app imports from this package alone.

| Export                                                                                                                                                                                                             | Kind             | Description                                                                                              | Page                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `useFieldInput`, `FieldInputProps`, `FieldInputKind`, `FieldInput`, `FieldControlBinding`                                                                                                                          | hook, types      | Binds a native text control to a field; every input is built on it.                                      | [useFieldInput](/docs/forms/use-field-input) |
| `InputHandle`                                                                                                                                                                                                      | type             | What an input does from code: `focus`, `setValue`, `reset`, `revealMessages`.                            | [useFieldInput](/docs/forms/use-field-input) |
| `FieldEventBase`, `FieldInputEvent`, `FieldChangeEvent`, `FieldValidateEvent`, `FieldCommitEvent`, `FieldBeforeInputEvent`, `FieldBeforeChangeEvent`, `FieldBeforeCommitEvent`, `FieldFocusEvent`, `FieldHandlers` | types            | The event objects, with the browser's `Event` as their native event, and the handlers that receive them. | [Events](/docs/forms/events)                 |
| `ChangeSource`, `CommitTrigger`, `TextInputDetails`, `NoDetails`                                                                                                                                                   | types            | Where a change came from and what ended an edit. Growable unions. Re-exported.                           | [Events](/docs/forms/events)                 |
