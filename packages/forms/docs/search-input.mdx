title: "SearchInput"
description: "SearchInput: a search box with a search icon and a clear button, an optional debounce, Enter to search at once and Escape to clear."
---

`SearchInput` is a search box, `<input type="search">`, whose value is a string, `null` when empty. It shows a search icon and a clear button, and reads the text after typing pauses for `debounce` milliseconds, when you ask for one; <Kbd>Enter</Kbd> reads it at once and <Kbd>Escape</Kbd> clears it. It takes the same props and fires the same [events](/docs/forms/events) as [`TextInput`](/docs/forms/text-input).

<Callout type="note" title="First iteration">
  This component is a first iteration and may change before the first release.
</Callout>

## When to use it

To filter or search as the user types (`onChange` with a `debounce`), or on <Kbd>Enter</Kbd> (`onCommit`).

## Example

```tsx title="App.tsx"
import { useState } from "react";
import { Field, SearchInput } from "@gridkitjs/forms";

export function App() {
  const [query, setQuery] = useState<string | null>(null);
  return (
    <>
      <Field label="Search orders" labelPosition="hidden">
        <SearchInput
          debounce={250}
          onChange={(event) => {
            setQuery(event.value);
          }}
        />
      </Field>
      <p>{query === null ? "All orders" : `Orders matching ${query}`}</p>
    </>
  );
}
```

## Props

Every prop of [`TextInput`](/docs/forms/text-input#props) that is not about passwords, multiline text or length, with these differences:

| Prop           | Type                    | Default    | Description                                                                                                                   |
| -------------- | ----------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `debounce`     | `number`                | `0` (none) | Milliseconds typing must pause before the text is read (`onBeforeChange`, `onChange`, `onValidate`). `onInput` fires at once. |
| `clearable`    | `boolean`               | `true`     | The clear button.                                                                                                             |
| `placeholder`  | `string`                | "Search"   |                                                                                                                               |
| `enterKeyHint` |                         | `"search"` | A phone keyboard's Enter key reads "Search".                                                                                  |
| `ref`          | `Ref<HTMLInputElement>` |            | The native control.                                                                                                           |

## Behaviour

- **Debounce.** A keystroke starts the wait again. <Kbd>Enter</Kbd> and leaving the field read the text at once, so `onChange` comes before `onCommit`; a clear drops the wait, and so does unmounting, which reads nothing.
- **Clearing.** The clear button, or <Kbd>Escape</Kbd>, fires `onClear`, then `onInput`, `onChange` and `onCommit` with `source` and `trigger` `"clear"`. The browser's own clear button is hidden, since this one works in every browser.
- **Floating label.** The search icon sits where a resting label would, so a floating label stays raised.

## Keyboard

| Key               | Does                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| <Kbd>Enter</Kbd>  | Commits now, reading the text and cancelling a pending debounce.             |
| <Kbd>Escape</Kbd> | Clears the text and takes the key; with no text, or read-only, passes it on. |
| <Kbd>Tab</Kbd>    | Commits, then focus moves on.                                                |

## Class names

| Class                                 | Element   | Description                                   |
| ------------------------------------- | --------- | --------------------------------------------- |
| `.gridkit-forms-search-input`         | `<div>`   | The root. States: is-compact, is-comfortable. |
| `.gridkit-forms-search-input-control` | `<input>` | The control.                                  |
| `.gridkit-forms-search-input-icon`    | `<span>`  | The search icon, hidden from screen readers.  |

The box, its adornments, clear button and spinner are `TextInput`'s; see its [class names](/docs/forms/text-input#class-names).

## Messages and localization

From `FormsMessages`: `searchPlaceholder` ("Search") and `clear` ("Clear").
