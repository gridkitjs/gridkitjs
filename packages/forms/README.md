# @gridkitjs/forms

React form inputs and form structure for GridKit, styled by the GridKit
themes to match the grid. Built on
[`@gridkitjs/forms-core`](https://www.npmjs.com/package/@gridkitjs/forms-core)
and [`@gridkitjs/forms-dom`](https://www.npmjs.com/package/@gridkitjs/forms-dom).

> **Not yet published.** The package is under development in this repository
> and is not on npm yet.

The types an app writes against are exported from this package, so an app
imports from it alone:

```ts
import type { Severity } from "@gridkitjs/forms";

const severity: Severity = "warning";
```

Full documentation: [github.com/gridkitjs/gridkitjs](https://github.com/gridkitjs/gridkitjs#readme)
