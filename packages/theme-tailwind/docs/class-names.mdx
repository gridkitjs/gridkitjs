`@gridkitjs/react` draws the grid as plain elements with semantic class names, and both themes, [`@gridkitjs/theme-tailwind`](/docs/theme-tailwind) and [`@gridkitjs/theme-css`](/docs/theme-css), style it through them alone. This page lists every class the grid renders, every state class, and every `data-gridkit-*` attribute, so your own CSS and your tests can target them.

## The rules

- Every class the grid renders starts with `gridkit-`, so none collides with a class of your app's own, and no rule of either theme matches an element outside the grid.
- A state is an `is-*` class (`is-selected`, `is-sorted-asc`), always on an element that also has a `gridkit-` class. Target it together with that class, as `.gridkit-grid-row.is-selected`, never on its own. Some states are ARIA attributes instead, such as `[aria-disabled="true"]` on a toolbar button; each part's table says which.
- A `data-gridkit-*` attribute carries an id or an index, for a test or a script to find an element by. The grid's own behaviours find their elements by these attributes, never by class.
- Class names, state classes and `data-gridkit-*` attributes are public API: they change only in a release that says so.

```css
.gridkit-grid-row.is-selected {
  outline: 1px solid var(--gridkit-accent);
}
```

```ts
const row = grid.querySelector('.gridkit-grid-row[data-gridkit-row-id="42"]');
```

## Layout

The grid is a set of siblings rather than one table, so the header and footer never scroll with the rows:

| Class                         | Element   | Description                                                                                                                                                       |
| ----------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.gridkit-data-grid-viewport` | `<div>`   | The grid's root: the toolbar, the group-by bar, the tables and the pager, in that order. Scrolls sideways when the columns are wider than it.                     |
| `.gridkit-data-grid-tables`   | `<div>`   | Holds the three tables and carries `role="grid"` (or `"treegrid"` while grouped), since the pattern needs one element around every row.                           |
| `.gridkit-data-grid`          | `<table>` | Each of the grid's tables (header, rows and footer), not the grid's root. Carries the border, hover and selectable modifiers below.                               |
| `.gridkit-data-grid-header`   | `<table>` | The header's table. Also a `.gridkit-data-grid`.                                                                                                                  |
| `.gridkit-data-grid-body`     | `<div>`   | The scroll container around the rows' table, the one `height` bounds, through `--gridkit-body-height`.                                                            |
| `.gridkit-data-grid-footer`   | `<table>` | The grand-total footer's table, while `aggregates` is non-empty. Also a `.gridkit-data-grid`.                                                                     |
| `.gridkit-sr-only`            | `<div>`   | The live region announcements are read from, clipped to nothing but left in the accessibility tree. Usable on anything of your own that should be read, not seen. |

### Borders, hover and selection

The `borders`, `hoverable` and `selectable` props put modifiers on each `.gridkit-data-grid` table:

| Class                         | Element   | Description                                                                     |
| ----------------------------- | --------- | ------------------------------------------------------------------------------- |
| `.gridkit-borders-horizontal` | `<table>` | `borders="horizontal"`: lines between rows.                                     |
| `.gridkit-borders-vertical`   | `<table>` | `borders="vertical"`: lines between columns.                                    |
| `.gridkit-borders-all`        | `<table>` | `borders="all"`: lines between rows and between columns.                        |
| `.gridkit-borders-none`       | `<table>` | `borders="none"`: no lines, the same as leaving `borders` out.                  |
| `.gridkit-no-hover-rows`      | `<table>` | `hoverable.rows` is `false`: no highlight on the row under the pointer.         |
| `.gridkit-no-hover-columns`   | `<table>` | `hoverable.columns` is `false`: no highlight on the column under the pointer.   |
| `.gridkit-no-hover-cells`     | `<table>` | `hoverable.cells` is `false`: no highlight on the cell under the pointer.       |
| `.gridkit-selectable-rows`    | `<table>` | Rows can be selected: turns on the pointer cursor and the text-selection guard. |
| `.gridkit-selectable-columns` | `<table>` | Columns can be selected, the same way.                                          |
| `.gridkit-selectable-cells`   | `<table>` | Cells can be selected, the same way.                                            |

## Toolbar

The grid's [toolbar](/docs/react/toolbar) is the first thing inside it, above the group-by bar. It sticks to the grid's start edge, so it stays in view while the tables scroll sideways, and keeps its entries on one row: what does not fit moves into "More". States are ARIA attributes, not classes.

| Class                               | Element    | Description                                                                                                                                                                                  |
| ----------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.gridkit-toolbar`                  | `<div>`    | The toolbar (`role="toolbar"`): its row, padding, surface and bottom border.                                                                                                                 |
| `.gridkit-toolbar-button`           | `<button>` | A command's button, a dropdown, or "More". `[aria-disabled="true"]` mutes it, `[aria-pressed="true"]` marks a toggle that is on, and `[aria-expanded="true"]` a dropdown whose menu is open. |
| `.gridkit-toolbar-button-icon`      | `<span>`   | The icon before a button's label; hidden when empty.                                                                                                                                         |
| `.gridkit-toolbar-button-indicator` | `<span>`   | The chevron after a dropdown's label.                                                                                                                                                        |
| `.gridkit-toolbar-more`             | `<button>` | The "More" button, holding the entries that do not fit. Also a `.gridkit-toolbar-button`. Sticks to the toolbar's end edge when the search box and custom entries alone overflow it.         |
| `.gridkit-toolbar-search`           | `<input>`  | The search box: `12rem`, or half the toolbar's width when that is less.                                                                                                                      |
| `.gridkit-toolbar-separator`        | `<div>`    | A separator (`role="separator"`).                                                                                                                                                            |
| `.gridkit-toolbar-spacer`           | `<div>`    | The free space, pushing what follows it to the far end.                                                                                                                                      |
| `.gridkit-toolbar-custom`           | `<div>`    | Holds what `renderToolbarItem` draws.                                                                                                                                                        |

A dropdown's menu, and "More"'s, are [menus](#overlays-and-menus) like the context menu's.

## Overlays and menus

The grid's [context menu](/docs/react/context-menu) renders into `document.body`, not inside the grid, so no scrolling ancestor clips it, and its selectors are top-level rather than under `.gridkit-data-grid`. States are ARIA attributes, not classes. How an overlay takes its colours is under [overlays and menus](/docs/theme-tailwind#overlays-and-menus) on the theme's overview.

| Class                             | Element  | Description                                                                                                                                                                                 |
| --------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.gridkit-overlay`                | `<div>`  | The positioned box around every menu, submenu and panel, `position: fixed` and above the grid. Carries the grid's `.gridkit-light`/`.gridkit-dark`.                                         |
| `.gridkit-menu`                   | `<div>`  | A menu (`role="menu"`): its surface, border, shadow and padding.                                                                                                                            |
| `.gridkit-menu-item`              | `<div>`  | An item. Focused (`:focus`) when the keyboard or the pointer is on it; `[aria-disabled="true"]`, `[aria-checked="true"]` and `[aria-expanded="true"]` (its submenu is open) style the rest. |
| `.gridkit-menu-item-icon`         | `<span>` | The icon before the label: empty when the item has none, so labels line up; a checked item's check.                                                                                         |
| `.gridkit-menu-item-label`        | `<span>` | The label.                                                                                                                                                                                  |
| `.gridkit-menu-item-shortcut`     | `<span>` | A key-combination hint after the label.                                                                                                                                                     |
| `.gridkit-menu-submenu-indicator` | `<span>` | The chevron on an item that opens a submenu.                                                                                                                                                |
| `.gridkit-menu-separator`         | `<div>`  | A separator (`role="separator"`).                                                                                                                                                           |

| Class                            | Element   | Description                                                                                           |
| -------------------------------- | --------- | ----------------------------------------------------------------------------------------------------- |
| `.gridkit-column-chooser`        | `<div>`   | The chooser (`role="dialog"`): a fixed width, its surface, border, shadow and padding.                |
| `.gridkit-column-chooser-search` | `<input>` | The search box.                                                                                       |
| `.gridkit-column-chooser-option` | `<label>` | A checkbox and its label: "Show all", or a column. Muted while its checkbox is disabled.              |
| `.gridkit-column-chooser-all`    | `<label>` | "Show all", set apart from the list below it. Also a `.gridkit-column-chooser-option`.                |
| `.gridkit-column-chooser-list`   | `<ul>`    | The columns, one `<li>` each. Scrolls inside itself past about ten, which does not close the chooser. |
| `.gridkit-column-chooser-empty`  | `<p>`     | "No matching columns", in place of the list when the search matches none.                             |

### Filter menu

Its buttons and fields are native, so a disabled button is `:disabled`; a sort entry for the direction the column sorts in is `[aria-pressed="true"]`, a value box marked invalid `[aria-invalid="true"]`, and a checklist value `[aria-checked="true"]` while checked. A marked box and its message take `--gridkit-error`, by default the accent turned red, as light or dark as the accent.

| Class                                    | Element               | Description                                                                                                                 |
| ---------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `.gridkit-filter-menu`                   | `<div>`               | The menu (`role="dialog"`): a fixed width, its surface, border, shadow and padding.                                         |
| `.gridkit-filter-menu-form`              | `<form>`              | Everything inside it, in a column. Submitting it applies the editor.                                                        |
| `.gridkit-filter-menu-sort`              | `<div>`               | The column's sort entries, set apart from what follows. Left out for a column that does not sort.                           |
| `.gridkit-filter-menu-sort-item`         | `<button>`            | A sort entry, drawn as a menu item.                                                                                         |
| `.gridkit-filter-menu-sort-icon`         | `<span>`              | The icon before its label: empty for "Clear sort", so labels line up; in accent while pressed.                              |
| `.gridkit-filter-menu-conditions`        | `<div>`               | The simple editor: its conditions in a column, And/Or between them.                                                         |
| `.gridkit-filter-menu-custom`            | `<p>`                 | "Custom filter" above either editor, or "Filtered by condition" above the checklist: a filter the editor can't show. Muted. |
| `.gridkit-filter-menu-condition`         | `<div>`               | One condition (`role="group"`): its operator picker on a line of its own, its value boxes sharing the next.                 |
| `.gridkit-filter-menu-operator`          | `<select>`            | A condition's operator picker.                                                                                              |
| `.gridkit-filter-menu-value`             | `<input>`, `<select>` | A value box: a true/false `<select>` on a boolean column; a "Between" has two. Red-bordered while `[aria-invalid="true"]`.  |

## Theme classes

The grid does not render these itself: you put one on the grid or an ancestor to [force a theme on one grid](/docs/theme-tailwind#forcing-a-theme-on-one-grid), and the grid copies it onto each `.gridkit-overlay` it opens.

| Class            | Element | Description                                          |
| ---------------- | ------- | ---------------------------------------------------- |
| `.gridkit-light` | Any     | Pins the grid and its overlays to the light palette. |
| `.gridkit-dark`  | Any     | Pins the grid and its overlays to the dark palette.  |

## State classes

Each state class sits beside the `gridkit-` class of the element it marks.

| Class                                | On                                                                | Description                                                                                              |
| ------------------------------------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `.is-selected`                       | `.gridkit-grid-row`, `.gridkit-header-cell`, `.gridkit-grid-cell` | A selected row, column header or cell. A selected cell wins over its row and column.                     |
| `.is-sorted-asc` / `.is-sorted-desc` | `.gridkit-header-sort-toggle`                                     | The column sorts ascending or descending.                                                                |
| `.is-grouped`                        | `.gridkit-header-group-toggle`                                    | The column is grouped.                                                                                   |
| `.is-filtered`                       | `.gridkit-header-filter-toggle`                                   | The column is filtered.                                                                                  |
| `.is-reorderable`                    | `.gridkit-header-cell`                                            | The column can be dragged to a new place.                                                                |
| `.is-resizing`                       | `.gridkit-header-cell`, `.gridkit-grid-cell`                      | The column is being resized.                                                                             |
| `.is-wrapped`                        | `.gridkit-header-cell`, `.gridkit-grid-cell`                      | The column's `wrap` wraps the header's or the cells' text rather than cutting it short.                  |
| `.is-dragging`                       | `.gridkit-header-cell`, `.gridkit-group-by-chip`                  | The header or chip being dragged.                                                                        |
| `.is-drop-before`                    | `.gridkit-header-cell`, `.gridkit-group-by-chip`                  | A drag will drop before this header or chip.                                                             |
| `.is-drop-after`                     | `.gridkit-header-cell`, `.gridkit-group-by-chip`                  | A drag will drop after this header or chip.                                                              |
| `.is-drag-target`                    | `.gridkit-group-by-bar`                                           | A chip, or a header that can be grouped, is being dragged.                                               |
| `.is-drag-blocked`                   | `.gridkit-group-by-bar`                                           | A header already grouped is being dragged at the bar, which won't take it.                               |
| `.is-expanded` / `.is-collapsed`     | `.gridkit-group-toggle`                                           | The group is open or closed.                                                                             |
| `.is-group-level-N`                  | `.gridkit-grid-group-row`, `.gridkit-grid-group-summary-row`      | The group's depth, `N` from 0 for a top-level group: `.is-group-level-0`, `.is-group-level-1` and so on. |

## Data attributes

| Attribute                      | On                                                                                                            | Holds                                                                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-gridkit-row-index`       | `.gridkit-grid-row`, `.gridkit-grid-group-row`, `.gridkit-grid-group-summary-row`                             | The row's place among every body row, counting group rows. It holds under virtualization, where `:nth-child` does not, and changes with every sort. |
| `data-gridkit-row-id`          | `.gridkit-grid-row`                                                                                           | The row's id, which stays with it however it moves.                                                                                                 |
| `data-gridkit-column`          | `.gridkit-header-cell`, `.gridkit-grid-cell`, `.gridkit-grid-footer-cell`, `.gridkit-grid-group-summary-cell` | The column's id.                                                                                                                                    |
| `data-gridkit-group`           | `.gridkit-grid-group-row`                                                                                     | The group's id.                                                                                                                                     |
| `data-gridkit-group-summary`   | `.gridkit-grid-group-summary-row`                                                                             | The id of the group it sums.                                                                                                                        |
| `data-gridkit-group-by-bar`    | `.gridkit-group-by-bar`                                                                                       | Nothing: it marks the bar.                                                                                                                          |
| `data-gridkit-group-chip`      | `.gridkit-group-by-chip`                                                                                      | The grouped column's id.                                                                                                                            |
| `data-gridkit-toolbar-item`    | A toolbar entry                                                                                               | The entry's `key`.                                                                                                                                  |
| `data-gridkit-toolbar-more`    | `.gridkit-toolbar-more`                                                                                       | Nothing: it marks the "More" button.                                                                                                                |
| `data-gridkit-menu-item`       | `.gridkit-menu-item`                                                                                          | The item's id.                                                                                                                                      |
| `data-gridkit-placement`       | `.gridkit-overlay`                                                                                            | Where the overlay sits beside what opened it, such as `"bottom-start"`, or `"top-start"` once flipped above; for pointing an arrow by.              |
| `data-gridkit-checklist-item`  | `.gridkit-filter-menu-option`                                                                                 | Nothing: it marks a value in the filter menu's checklist.                                                                                           |
| `data-gridkit-checklist-index` | `.gridkit-filter-menu-option`                                                                                 | The value's place in the whole list, of which only the visible part is drawn.                                                                       |
